MIDI Macros

midi-macros is a browser-based composition tool built on @perry-rylance/midi and @perry-rylance/midi-macros. Write TypeScript in the editor, then use the controls here to play it back.

No saved projects yet.

Please see README.md for more detail on the available macros.
